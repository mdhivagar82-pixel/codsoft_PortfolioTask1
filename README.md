# Personal Portfolio Website 🌐

A simple and professional personal portfolio website built using HTML and CSS as part of the CodSoft Internship – LEVEL 1 TASK 1.
This project presents personal information, technical skills, resume, and contact details in a clean and responsive layout.

## 🔗 Live Demo
👉 Click here to view the live project:
 **https://mdhivagar82-pixel.github.io/codsoft_PortfolioTask1/**

## Features
- Responsive navigation bar
- Hero section with introduction and profile image
- About section with short bio
- Skills section displayed in grid format
- Resume section with downloadable PDF
- Contact section with email and phone details
- Footer with copyright information
